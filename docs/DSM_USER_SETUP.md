# How to Set Up a Dedicated DSM User for NAS-Pulse / 如何为 NAS-Pulse 配置专用群晖账号

[English](#english) • [中文说明](#中文说明)

---

## English

To protect your Synology NAS, **never use your primary root/admin account** for external scripts or monitoring tools. Follow this 2-minute guide to create a dedicated, secure user for NAS-Pulse.

### 🔑 Why Administrator Group is Required (DSM 7+ WebAPI Nuance)

In Synology DSM 7+, physical hardware sensors (CPU temperature, fan speed, system health) and disk SMART tables are governed by the `core_sys_info.SysInfo` WebAPI.

> **Crucial Rule:** Synology strictly restricts these low-level sensor endpoints to users in the **`administrators`** group. Any standard non-admin user will trigger:
> ```
> Error 105 - Insufficient privilege
> ```

Therefore, the best-practice security model is to **create a dedicated operational account (`nas_doctor`) in the `administrators` group, but explicitly strip away access to all sensitive shared folders and non-essential applications**.

### 🛠️ Step-by-Step Setup Guide

#### 1. Create User
1. Open **Synology DSM** in your browser.
2. Go to **Control Panel** → **User & Group** → **Create**.
3. Name: `nas_doctor` (or any username you prefer).
4. Description: `Dedicated diagnostics account for NAS-Pulse`.
5. Password: Set a strong, unique password (e.g. 24+ random characters generated by a password manager).
6. Uncheck **"Disallow the user to change account password"**.

#### 2. Assign Group
- In the **Join groups** step, check **`administrators`**.

#### 3. Lockdown Shared Folder Permissions (Principle of Least Privilege)
- In the **Assign shared folders permissions** step:
- Check **No Access** for all personal or sensitive shared folders (such as `homes`, `docker`, `family_photos`, `documents`, `backups`).
- NAS-Pulse does not need filesystem read access to perform hardware & Docker diagnostics.

#### 4. Lockdown Application Permissions
- In the **Assign application permissions** step:
- Check **Deny** for all user applications (e.g. `Synology Drive`, `File Station`, `Surveillance Station`, `Audio Station`, `Video Station`).
- Allow only core DSM access so the WebAPI can authenticate.

#### 5. Validate with NAS-Pulse
Run the self-check diagnostic command in your terminal:
```bash
nas-pulse doctor
```
Or run the interactive wizard:
```bash
nas-pulse setup
```

## 中文说明

为了确保群晖 NAS 的最高安全性，**切勿直接使用日常的个人主账号或 Root 级大号**来运行监控脚本。请参考以下 2 分钟极速指南，为 NAS-Pulse 创建专用的最小权限账号。

### 🔑 为什么必须加入 administrators 管理员组 (DSM 7+ WebAPI 底层逻辑)

在群晖 DSM 7+ 中，硬件物理传感器（CPU 温度、风扇转速、系统健康体征）和物理硬盘 SMART 骨骼状态由 `core_sys_info.SysInfo` WebAPI 负责分发。

> **核心限制**：群晖官方对物理底层传感器设置了严格的权限分层。任何标准受限用户调用此类接口，群晖均直接拒绝并返回：
> ```
> Error 105 - Insufficient privilege (权限不足)
> ```

因此，最符合安全原则（Least Privilege）的最佳实践是：**创建一个专用的运维账号（如 `nas_doctor`），将其加入 `administrators` 用户组，但在后续权限配置中显式剥离所有敏感文件夹的读写权限及应用权限**。

### 🛠️ 步骤指引

#### 1. 新增用户
1. 在浏览器中打开群晖 DSM 管理后台。
2. 进入 **控制面板** → **用户与群组** → 点击 **新增**。
3. 用户名：`nas_doctor`（或你喜欢的名字）。
4. 描述：`NAS-Pulse 诊脉仪专用诊断账号`。
5. 密码：生成一个强密码（推荐 24 位以上随机字符）。

#### 2. 加入群组
- 在 **加入群组** 步骤中，勾选 **`administrators`**。

#### 3. 封锁共享文件夹访问 (数据完全隔离)
- 在 **指派共享文件夹权限** 步骤中：
- 将所有私有或重要文件夹（如 `homes`, `docker`, `family_photos`, `documents`, `backups` 等）全部勾选为 **禁止访问 (No Access)**。
- NAS-Pulse 诊断体温与容器只需走系统管理 API，**完全不需要读取你的任何硬盘文件**。

#### 4. 封锁应用程序权限
- 在 **指派应用程序权限** 步骤中：
- 将所有上层套件（如 `Synology Drive`, `File Station`, `Surveillance Station`, `Audio/Video Station`）全部勾选为 **拒绝 (Deny)**。
- 仅保留基础 DSM 管理访问以供 WebAPI 认证。

#### 5. 运行连通性测试
在终端中执行自检排错命令：
```bash
nas-pulse doctor
```
或直接运行配置向导：
```bash
nas-pulse setup
```
看到以下提示即表示安全配置大功告成：
```text
✔ WebAPI 连通测试通过！成功感知 CPU 传感器与硬件状态。
```
